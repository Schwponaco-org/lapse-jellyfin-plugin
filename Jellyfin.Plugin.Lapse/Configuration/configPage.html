Bulk sync

A bulk run can move a subtitle that was already right. With File output set to write a new file, nothing you have now can be lost, and every run can be undone below.
The Sync subtitles task under Scheduled Tasks does the same on a schedule you give it there.

Libraries

A turned on library can be synced by hand or by a bulk run. New items syncs what is added from then on, Schedule goes over the whole library. What they do is set under Automation.

Multi engine sync

Experimental. When LAPSE is unsure, alass and ffsubsync have a go too, and each answer becomes an extra subtitle track to pick from. It makes more work per sync, so it is off by default.
Checking what is installed...
Play the item, switch between the answers and keep the one that fits from the subtitle menu. The original stays untouched until then.

Which engines to ask

No match usually means the subtitle is for another release, which the other engines rarely fix.
They read only .srt, .ass, .ssa and .vtt. Picture subtitles only ever get LAPSE's answer.
On a large library this leaves far more answers waiting than anyone will go through.

Automation

What runs nobody is watching do: schedules, new items, bulk runs and the Radarr, Sonarr and Bazarr calls. Pressing Sync on an item is not affected.

What an automatic run does

A nightly run then only works on what is new. Turn it off for one run after changing engine settings.
In libraries with New items on, a subtitle added later by Jellyfin, Bazarr or by hand is synced too.
Automatic translation (experimental)
Sends every subtitle an automatic run touches to the translation provider. Check what your provider charges first. Translations go to a new file and never replace the original.
A language code such as da, de or es.
Otherwise every run pays for the whole library again.

Access

Who besides administrators can sync, shift, convert and translate subtitles from an item's menu. These settings pages stay administrator only.

Nothing automatic touches what is on this list. A series or folder covers everything in it. An ignored item can still be synced from its own menu.
Covers everything under it, even what Jellyfin has not scanned yet.

Translation

Experimental. Sends the subtitle text to a service outside Jellyfin, and quality varies a lot by provider and language. Translate is in an item's Advanced dialog, and always writes a new file.

Defaults

A language code such as da, de or es. Saves typing it on a TV remote.
Leave empty to let the provider work it out.

Subtitle appearance

In the web player

Restyles .srt and .vtt subtitles while they play, without touching the files. This is the default for everyone, and each user can change it from Subtitle tools in the player.
For text burnt into the bottom of the picture. ASS tracks keep their own position.
This is what a subtitle will look like.

Readable subtitles

Writes the style into a copy of the subtitle file, so every client shows it, not only the browser. Use Readable subtitles in an item's menu to write one.
Checking which fonts are installed...
Downloads OpenDyslexic (SIL Open Font License) into Jellyfin's font folder and turns on the server's fallback fonts.
Any font in that folder, by name, such as OpenDyslexic.
OpenDyslexic has no Arabic, Hebrew, Thai or CJK letters. Leave empty for Arial.
Against a 1080p picture, so it scales with the video.
Replacing changes it for everyone. The original is kept as a backup either way.

Experimental

These lean on services and apps outside Jellyfin, so they can break when those change. None of it is needed for syncing.

Subtitles from OpenSubtitles

Also adds Find subtitles online to each item's menu and to Subtitle tools in the player.
Codes or names in order of preference, such as da, en.
Register a consumer at opensubtitles.com to get one.
Searching needs only the key. Downloads need an account and count against its daily quota.

Radarr, Sonarr and Bazarr

A new film or episode is synced as soon as Jellyfin has scanned it in.
In Radarr or Sonarr: Settings, Connect, Webhook, method POST, On Import. The URL is a password, keep it to yourself.
In Bazarr: Settings, Subtitles, Custom Post-Processing. Bazarr needs curl and to reach Jellyfin at this address.

Notify me when a bulk run is done

Leave a box empty to turn it off. Both addresses work like passwords.

Extract embedded subtitles

Runs as Extract embedded subtitles under Scheduled Tasks. The video is never changed.
