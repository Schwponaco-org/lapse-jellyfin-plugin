Libraries

Automatic sync can occasionally move a subtitle that was already fine. Set File output to one of the sidecar modes before turning on bulk or scheduled syncing and nothing you have now can be lost.
Turn a library on to make everything in it eligible for syncing. A schedule syncs that library on its own frequency and time.

Sync status

Items with no external subtitle are hidden by default. An item counts as synced once every external subtitle it currently has been synced at least once.

Bulk sync

Automatic sync can occasionally move a subtitle that was already fine. Set File output to one of the sidecar modes before running this and nothing you have now can be lost.
There's also a "Sync subtitles" task under Scheduled Tasks that does the same thing on Jellyfin's own schedule.

File output

This page is about synced files. Changing a subtitle's format, and what happens to the file it was converted from, is on the Conversion page instead.

Confidence

LAPSE only. LAPSE measures how far its answer stands out from every other offset it tried, and calls a result solid, unsure or nothing on that basis. This is the bar it has to clear, passed to the engine as --confidence. alass and ffsubsync report nothing of the kind, so their results are always written.

Experimental

Everything on this page is experimental. It leans on services and apps outside Jellyfin, so it can break when they change, and none of it is needed for normal syncing.

Fetch missing subtitles from OpenSubtitles Experimental

When a sync is asked for on an item that has no subtitle at all, go and get one first, then sync it. Items that already have a subtitle are untouched.
Two letter code, e.g. en, da, es, de.
Register a consumer at opensubtitles.com to get one.
Searching works with just the key. Downloading needs an account, and comes out of that account's daily quota.

Radarr and Sonarr Experimental

Both apps can call a URL when they import something. Point them here and a new episode or film gets synced as soon as Jellyfin has scanned it in. Nothing polls: they call, LAPSE waits for the item to appear, then syncs it. If it never appears the scheduled sync picks it up later.
In Radarr or Sonarr: Settings, Connect, add a Webhook, method POST, paste this as the URL, and tick "On Import" (and "On Upgrade" if you want re-imports synced too). The secret in the URL is the only thing protecting it, so treat it like a password.
