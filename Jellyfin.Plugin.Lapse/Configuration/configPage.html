LAPSE

Sync subtitles that have drifted out of time

Engines

Libraries

Note: automatic sync may occasionally shift a correctly timed subtitle. It is recommended to configure File Output to Sidecar mode before enabling bulk or scheduled sync.
Turn a library on to make everything in it eligible for syncing. A schedule syncs that library on its own frequency and time.

Items

Items with no external subtitle are hidden by default. An item counts as synced once every external subtitle it currently has been synced at least once.

Bulk sync

Note: automatic sync may occasionally shift a correctly timed subtitle. It is recommended to configure File Output to Sidecar mode before enabling bulk or scheduled sync.
There's also a "Sync subtitles" task under Scheduled Tasks that does the same thing on Jellyfin's own schedule.

Subtitle to subtitle

Line up any two subtitle files against each other, without going through an item.
Suggested from the input file's name - change it to whatever you like. It has to end in .srt, .ass, .ssa or .vtt.
Always runs standard mode with the default engine.

File output

When confidence is below threshold

LAPSE engine only. LAPSE reports how much of the subtitle ended up sitting on speech, and a low score usually means the subtitle isn't for this video at all. alass and ffsubsync report no confidence, so nothing here applies to them and their results are always written.

Translation

To use this: press Advanced on an item, either from its three-dot menu or from the Items list, then use the Translate box in that dialog. This page is only where the providers and their defaults are set up.
Translation always writes a new file next to the original and never touches it. Sync and translation are independent.

Defaults for new jobs

Lines scoring below this are counted separately, and optionally left untranslated. This is the translation threshold, and has nothing to do with the sync confidence under File output.

Subtitle appearance

Applies to SRT and VTT. ASS/SSA support is partial. PGS and image-based subtitles are not affected.
This restyles what the player draws during playback. Nothing on disk changes, so turning it off puts everything straight back.
This is what a subtitle will look like.

Advanced

None of this needs setting up. The defaults are what most people want.

Engine auto-update

Keeps every engine you have installed up to date once a day. Engines that are not installed are ignored, and an engine you pointed at your own binary is never replaced. Turning this off is not recommended - engine releases carry sync quality fixes.
